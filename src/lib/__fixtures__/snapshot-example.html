Understanding Link Rot

Link rot is the phenomenon where hyperlinks stop working because the content they point to has been moved, deleted, or changed. This is a significant problem for online publishing and digital preservation.

"The web is not a permanent medium. Links break. Pages disappear. Content is moved or deleted. This is not a bug — it is a feature of how the web works."

— Internet Archive Foundation

Causes of Link Rot

There are several common causes of link rot:

  • Website redesigns that change URL structures
  • Content being removed without proper redirects
  • Domain expiration and loss of hosting
  • Company mergers and acquisitions

Preventing Link Rot

Several strategies can help prevent link rot:

  1. Use of persistent identifiers like DOIs
  2. Archiving through services like the Wayback Machine
  3. Setting up proper redirect chains when content moves
  4. Citing archived versions of pages
